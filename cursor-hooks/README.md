# DevPractice Cursor Hooks

Captures prompts and AI tool executions to turn your daily workflow into a personalized training playground.

## Installation
1. Copy or symlink the `.cursor` directory into your project root.
2. In Cursor's terminal or settings, set the API token:
   ```bash
   export DEVPRACTICE_TOKEN="your_token_here"
   ```
3. Use Cursor normally; hooks are fully async and never block.
