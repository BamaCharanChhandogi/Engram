# DevPractice Claude Plugin

This plugin intercepts prompts and tool actions to build your DevPractice profile.

## Installation
1. Move or symlink this directory into your project's root as `.claude-plugin`.
2. Configure environment variables in your terminal before running Claude Code:
   ```bash
   export DEVPRACTICE_TOKEN="your_personal_token"
   export DEVPRACTICE_API="https://your.api.endpoint" # Optional
   ```
3. Run `claude` and work as usual!
